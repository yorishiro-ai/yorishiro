# 公開 API ガードレール

このリポジトリでは、変更された `src/`、`ee/`、`edition/` の手書き Rust に新しく追加された広域 `pub` 宣言を検査します。

公開宣言を変更する前に `make public-api-check` を実行してください。

ローカルでは、作業ツリーと `HEAD` を比較します。
CI では `PUBLIC_API_BASE_REF` と `PUBLIC_API_HEAD_REF` に明示的な base と head の ref を渡します。
新しいブランチへの最初の push では、`github.event.before` の全ゼロ値を Git の空ツリーとして扱うため、最初のコミット全体を新規追加として検査します。
強制 push の検査はワークフローの checkout に存在するコミットに制限されるため、到達可能な base と head のコミットが必要です。

検査では、base と head の正規化したパス、宣言種別、シンボルを比較します。
書式や宣言順を変えても結果は変わりません。

## 対象範囲

`src/models/_entities/` と `src/dtos/` 以下の生成ファイルは明示的に対象外です。

マイグレーション、テスト、バイナリ、依存関係、実行時の挙動、無関係な公開 API は対象外です。

これは対応形式を限定した軽量スキャナーであり、完全な Rust パーサーではありません。

属性、ジェネリクス、`pub const fn`、`pub async fn`、`pub unsafe fn`、制限付き可視性、`pub use`、公開の struct、enum、trait、type、const、static、module 宣言を扱います。

これは回帰を検知するためのガードレールであり、`pub` の一律禁止でも、可視性を一括整理する作業でもありません。

## レビュー指針

許可リストには、新しく承認した宣言だけをパス、種別、シンボル、具体的な理由とともに記録します。

例外が必要な場合は、レビュー担当者が次の意図された境界を確認し、簡潔な理由欄に該当する境界を記載させてください。

- `integration-test`: 外部の統合テスト crate から利用する定数、ヘルパー、フィールド、型。
- `openapi-transport`: utoipa、Axum、REST、OpenAPI のリクエスト、レスポンス、ルーター、マクロの公開面。
- `mcp`: rmcp のツール引数、ハンドラー、ルーター、マクロの公開面。
- `seaorm-facade`: 手書きの SeaORM ファサードと生成エンティティの境界。
- `auth-provider-resolver`: 外部から実装可能な認証、プロバイダー、リゾルバーの接続点。
- `app-hooks`: `App`、`Hooks`、アプリケーションの合成入口。
- `loco-task-worker`: Loco の Task と Worker の登録入口およびペイロード。
- `ce-ee-composition`: `edition/` にある組み立ての起点と、`src/` がそこへ公開する入力。
- `worker-registry`: タグ、キュー、Loco への登録の導出元となるワーカーレジストリ。
- 過去から存在する公開宣言を列挙する必要はありません。

これらのラベルはレビュー用の指針にすぎません。
許可リストに追加の列を設けるものでも、自動的に承認されるカテゴリでもありません。

新しい宣言は、`pub(crate)`、`pub(super)`、非公開へ狭めるか、該当する境界を記載した簡潔な理由とともに `scripts/public_api_allowlist.tsv` へ意図的に追加してください。

検査を黙らせるだけの目的で許可リストを更新しないでください。
呼び出し元を確認し、広い可視性が必要な理由を記録してください。
マクロが生成する API やスキャナーの対応外である Rust の形式も、同じように手動レビューが必要であり、この字句ガードレールの対象外です。

このポリシーは、#455 の完了した棚卸しと、PR #463 でマージされた #456 の可視性縮小（`b492d60bea35f26f3231b982020f3f0b1a96b64e`）を基準にしています。

変更されていない既存の公開宣言は base と head の両方に存在するため、自動的に合格します。

base または head の ref を解決できない場合は、誤った範囲を検査せず明示的に失敗します。

検査に失敗すると、具体的なパスとシンボル、ポリシー、更新対象の許可リストを表示します。
