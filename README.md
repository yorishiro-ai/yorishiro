# Yorishiro (依り代)

**English** | [日本語](README.jp.md)

A knowledge store where you define your own data structures and search by meaning, not just keywords.

```console
$ docker run -d --name yorishiro --restart unless-stopped -p 80:5150 \
    ghcr.io/yorishiro-ai/yorishiro:latest
```

Then follow [first run](https://yorishiro-ai.github.io/wiki/installation/first-run/) to create your account and API key.

Documentation, installation options, configuration, and MCP tools are in the [wiki](https://yorishiro-ai.github.io/wiki/).
