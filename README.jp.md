# Yorishiro (依り代)

**[English](README.md)** | 日本語

自分のデータ構造を定義し、キーワードだけでなく意味で検索できるナレッジストア。

```console
$ docker run -d --name yorishiro --restart unless-stopped -p 80:5150 \
    ghcr.io/yorishiro-ai/yorishiro:latest
```

続けて[初回起動](https://yorishiro-ai.github.io/wiki/ja/installation/first-run/)に従い、最初のアカウントと API キーを作成してください。

インストール方法、設定、MCP ツールなどのドキュメントは [wiki](https://yorishiro-ai.github.io/wiki/ja/) にあります。

## 開発に参加する

開発手順は [CONTRIBUTING.md](CONTRIBUTING.md)（英語）を参照してください。このリポジトリで作業する AI エージェントは、まず [AGENTS.md](AGENTS.md)（英語）を読んでください。
